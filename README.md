## What This Is

The Jones Senior Project applies a proprietary public-record intelligence model to four executive questions:

- How is the CECO-Thermon transaction structured from the outside?
- Where could integration execution risk emerge during the 36-month synergy window?
- What are competitors signaling through AI-enabled products, operating investments, and digital platforms?
- Which near-term decisions could protect value without exposing the proprietary framework behind the analysis?

This is an executive introduction asset, not a full framework disclosure.

## Core Positioning

The transaction appears structurally strong from the public record:

- Approximately `$2.2B` announced stock-and-cash combination.
- At least `$40M` in annual cost synergies targeted within 36 months.
- Stockholder approval announced by both companies.
- CECO Q1 2026 public signals included backlog above `$1B` and `2.2x` book-to-bill.

The operating question is what happens after close:

> The 36-month synergy window is also the window in which workflow automation, predictive maintenance, compliance intelligence, and customer-facing analytics can either protect value or fall behind the competitive set.

## Deployment

To deploy on GitHub Pages:

1. Add `index.html` to the repository root.

3. In GitHub, go to `Settings > Pages`.
4. Set the source to the branch and root folder containing `index.html`.
5. Publish.
